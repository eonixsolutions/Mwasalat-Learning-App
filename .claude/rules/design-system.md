# EONIX DESIGN SYSTEM

## UI Personality

The UI must feel:
- Modern
- Clean
- Premium
- Structured
- Minimal
- Startup/SaaS inspired

Avoid:
- Over-colorful layouts
- Random Tailwind colors
- Heavy shadows
- Cluttered spacing

# COLOR DISTRIBUTION

- 70% neutral backgrounds and surfaces
- 20% teal branding and structure
- 10% coral actions and highlights

The interface should remain mostly light and clean.

---


# UI RULES

- Use rounded-2xl frequently
- Use soft shadows only
- Keep layouts breathable
- Use generous spacing
- Coral only for CTAs
- Teal for structure
- Avoid random Tailwind palette colors
